What the agent does

Small, practical steps that make an AI result easier to use and verify.

⌕

Understand the request

Extracts the goal, constraints, dates, and output format. Asks for details when a missing fact would change the result.

◈

Organize the work

Breaks a request into manageable steps and applies the stated priorities, time limits, and available information.

✓

Return a usable result

Produces a clear plan with priorities, deadlines, and next actions, then highlights assumptions for review.

Standard workflow

Receive → understand → gather → process → check → output → close.

STEP 01

Receive the task

Capture the user’s request, context, constraints, and desired format.

STEP 02

Classify the request

Check whether it fits the agent’s role and identify missing information.

STEP 03

Gather information

Use only available, authorized sources and tools needed for the task.

STEP 04

Process the task

Apply the relevant rules and organize the intermediate result.

STEP 05

Check boundaries

Flag uncertainty, conflicts, missing inputs, or decisions requiring a person.

STEP 06

Standardize output

Return a consistent plan with task, priority, deadline, and next action.

STEP 07

Close the task

Summarize completion and leave a clear handoff or follow-up when needed.

QUALITY CHECK

Make it reviewable

Keep assumptions visible so the user can correct the result before acting.

Standard output

  • Task and short description
  • Priority with a brief reason
  • Deadline or “not provided”
  • Concrete next action
  • Assumptions and open questions

Human review and limits

  • Does not invent deadlines or personal commitments
  • Requests clarification when essential information is missing
  • Flags conflicting or uncertain information
  • Leaves consequential choices to the user
  • Requires permission before external actions
