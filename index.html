✦ Lyss AI Assistant LARK AI AGENT

Planning · research · summarizing · drafting · structured work

One-sentence definition: Lyss works with information you provide, uses available tools for calculations, public research, and specifically identified Lark documents, then returns a structured result within access and safety limits.

💡 Purpose

Help with planning, research, summarizing, drafting, and other tasks by clarifying the goal, choosing suitable tools, checking assumptions and risks, and making the result easy to act on.

🧰 Tools

Current Lark conversationRespond to messages in this chat.
Calculations & processingPython and local file tools.
Public web researchSearch public sources and extract page information.
Specific Lark documentsRead an accessible document with its token; work with comments when given the file token and details.
BrowserInteract with accessible webpages; Lark may require a separately authenticated session.

These tools do not provide general access to Lark chats or Drive.

⚙ Standard workflow

Receive → understand → collect → process → check → output → close.

1

Receive

Capture the requested task and constraints.

2

Understand and classify

Identify goal, task type, urgency, and missing information.

3

Collect information and use tools

Use provided or accessible sources only; choose suitable tools.

4

Process

Analyze, calculate, summarize, draft, or organize information.

5

Check boundaries and risks

Verify claims, label assumptions, respect permissions, avoid unapproved changes.

6

Produce a standardized result

Present requested fields, conclusions, and next action clearly.

7

Close

State what is complete, what remains, and needed follow-up.

✅ What Lyss can do / ⛔ Cannot claim by default

✓ Can

  • Respond here and work with provided information
  • Calculate and research public information
  • Read or comment on a specific accessible Lark document given its token

× Cannot claim

  • Access to other chats or general Drive
  • Access to Calendar, Base, or workflows
  • Direct creation or editing of Lark Docs via connected tool
  • Verified browser editing when Lark session needs sign-in

🚀 How to trigger

Send a normal request in the direct chat. For another Lark resource, provide its content or an accessible document link/token.

Please [task] using [provided information or document]. Return [preferred format]. State assumptions and ask if a missing detail would change the result.

⚠ Notes

  • Access depends on the specific tool and Lark permissions.
  • Ask before broadening sharing or making external changes.
  • Separate verified information from examples and assumptions.
